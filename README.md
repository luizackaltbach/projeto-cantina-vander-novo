# projeto-cantina-vander-novo
Projeto hackaton 25.09 para controle de pedidos de cantina escolar novo pois o outro repositório corrompeu

É um aplicativo desenvolvido para modernizar, organizar e agilizar o funcionamento de cantinas em ambiente escolar. O projeto substitui os antigos registros manuais em cadernos por um sistema digital eficiente que gerencia pedidos, vendas, estoque e o controle financeiro dos alunos.
O principal objetivo é eliminar o trabalho manual dos atendentes e reduzir as filas nos intervalos através de pedidos antecipados, fazendo com que a gestão de pagamentos e relatórios seja mais eficiente.

O sistema possui três níveis de acesso, cada um com funcionalidades específicas:

Para os alunos, é possível consultar o cardápio e ver os itens disponíveis em tempo real, além de realizar pedidos antecipados para os próximos intervalos, evitando filas. O acompanhamento dos gastos e histórico de consumo são visíveis no aplicativo, e a apresentação do pedido no balcão deixa a retirada mais prática.

Os responsáveis possuem acesso ao extrato para monitorar detalhadamente os produtos consumidos pelos filhos, valores e datas, além de poderem depositar créditos na conta do aluno. É possível também definir um valor máximo para os gastos dos dependentes, justamente pelo fato de as contas estarem vinculadas.

Os funcionários da cantina, por sua vez, conseguem realizar o cadastro, edição e controle de estoque de produtos, além da visualização e atualização do status dos pedidos antecipados. Quanto às vendas no balcão, há o registro rápido de compras. Os trabalhadores acompanham o histórico de vendas e fechamento mensal.

Observações importantes:

O app não substitui a compra presencial. Alunos sem pedido antecipado compram normalmente no balcão. Além disso, o sistema permite que a conta do aluno fique negativa até o R$ 250,00; acima desse valor, novas compras a prazo são bloqueadas. O sistema impede a finalização de pedidos de itens marcados como esgotados.

Tecnologias utilizadas:

Design: Telas e protótipo desenhados no Figma com auxílio da IA do Figma.
Desenvolvimento: Aplicativo em Java utilizando o Android Studio.
Banco de Dados: Modelagem do banco de dados no MySQL Workbench.
Inteligência Artificial: Código e lógica otimizados via Claude.ia, ChatGPT (e Codex) e Gemini.

Como instalar e rodar o aplicativo?

1. Você encontra o arquivo executável (.APK) (pode ser no WhatsApp, no Google Drive, no e-mail, em um site...);
2. Clicar no arquivo no celular para iniciar a instalação;
3. O Android mostrará um aviso de segurança dizendo que o app veio de uma fonte desconhecida. Então clicar em "Configurações" (na própria mensagem) e marcar a opção "Permitir desta fonte" (ou "Autorizar a instalação");
4. Voltar para a tela anterior e clicar em "Instalar".
